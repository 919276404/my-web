# 北京市食品安全全链条数字化平台 - 系统流程图

## 1. 系统主流程

```mermaid
flowchart TD
    A[系统登录] --> B[主界面]
    B --> C{选择功能模块}
    C -->|抽样检验| D[抽样检验模块]
    C -->|检验项目解读| E[检验项目解读模块]
    C -->|费用管理| F[检验费/样本费/打包价管理]
    C -->|统计分析| G[统计分析模块]
    C -->|计划管理| H[计划智能辅助管理]
    C -->|经费决算| I[经费决算管理]
    C -->|风险警示| J[监测风险警示模块]
    C -->|信息发布| K[监测结果信息发布管理]
    C -->|总结报送| L[监测总结和计划报送管理]
    
    D --> M[基本统计/工作报表]
    E --> N[检验项目/类别管理]
    F --> O[费用标准配置]
    G --> P[分析报表/分析报告]
    H --> Q[规则管理/执行/反馈]

    O --> B
    P --> B
    Q --> B

    S --> B
    T --> B
    U --> B
```

## 2. 抽检工作主流程

```mermaid
flowchart TD
    A[制定抽检计划] --> B[计划智能辅助管理]
    B --> C{规则触发提醒}
    C -->|高频超标主体| D[重点抽检主体提醒]
    C -->|季节周期风险| E[专项抽检提醒]
    C -->|区域品类风险| F[区域重点品类提醒]
    D --> G[纳入计划]
    E --> G
    F --> G
    
    G --> H[抽样检验]
    H --> I[数据录入]
    I --> J[检验项目解读]
    J --> K[结果分析]
    K --> L{是否合格}
    L -->|合格| M[数据归档]
    L -->|不合格| N[问题处置]
    
    N --> O[风险警示]
    O --> P[警示推送]
    P --> Q[反馈处置]
    Q --> R[信息发布]
    R --> S[归档保存]
    
    M --> S
```

## 3. 风险警示流程

```mermaid
flowchart TD
    A[风险警示规则配置] --> B[规则可视化自定义]
    B --> C[库表选择与关联]
    C --> D[判定字段选取]
    D --> E[运算关系定义]
    E --> F[自定义函数配置]
    F --> G[执行策略配置]
    G --> H[规则保存]
    
    H --> I[规则执行]
    I --> J{触发方式}
    J -->|实时执行| K[抽检数据新增触发]
    J -->|定时执行| L[按日/周/月执行]
    J -->|手动执行| M[立即执行测试]
    
    K --> N[数据分析]
    L --> N
    M --> N
    
    N --> O{识别风险}
    O -->|无风险| P[结束]
    O -->|有风险| Q[生成警示信息]
    
    Q --> R{警示等级}
    R -->|红色警示| S[系统弹窗+多渠道推送]
    R -->|橙色/黄色警示| T[系统消息推送]
    
    S --> U[接收人查看]
    T --> U
    
    U --> V[状态反馈]
    V --> W[已查看/已派单/已处置]
    W --> X[记录归档]
    X --> Y[历史查询]
```

## 4. 信息发布流程

```mermaid
flowchart TD
    A[信息发布筛选] --> B[选择拟公示样品]
    B --> C[自动生成公示编号]
    C --> D[添加发布信息]
    D --> E[附件自动生成]
    E --> F{附件类型}
    F -->|合格样品信息表| G1[生成合格表]
    F -->|不合格样品信息表| G2[生成不合格表]
    F -->|信用归集表| G3[生成信用表]
    F -->|信息核对表| G4[生成核对表]
    
    G1 --> H[附件审批流转]
    G2 --> H
    G3 --> H
    G4 --> H
    
    H --> I[待审批附件列表]
    I --> J[审核人核对]
    J --> K{审核结果}
    K -->|通过| L[下一环节审批]
    K -->|驳回| M[补充修改]
    M --> J
    
    L --> N{是否最终审批}
    N -->|否| L
    N -->|是| O[信息公示]
    O --> P[归档保存]
```

## 10. 数据填报流程

```mermaid
flowchart TD

    I --> J

```
